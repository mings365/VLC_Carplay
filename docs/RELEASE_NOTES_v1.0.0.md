# VLC CarPlay v1.0.0

基于 VLC for iOS 的非官方 CarPlay 视频分支。手机选择媒体，车机显示视频并提供播放/暂停、队列切换、进度跳转、字幕和音轨切换。播放时控制栏自动隐藏，轻点画面再次显示。

**安装：** 下载 `VLC-CarPlay-v1.0.0-TrollStore.ipa` 并通过 TrollStore 安装；越狱环境需能保留 `SBStarkCapable` 权限。普通 Apple ID 侧载不支持此旧版窗口路径。仅在驻车时使用，应用没有自动车辆运动状态检测。车机完整文件浏览和原有 CarPlay 音频模板不包含在此视频安装包中。

---

An unofficial VLC for iOS fork with video output to a CarPlay display. Select media on the iPhone, then control playback, queue navigation, seeking, subtitles, and audio tracks on the car screen. Controls hide during playback and reappear when the video is tapped.

**Install:** Download `VLC-CarPlay-v1.0.0-TrollStore.ipa` and install it with TrollStore. A jailbroken installation must preserve the `SBStarkCapable` entitlement. Ordinary Apple ID sideloading does not support this legacy window path. Use video only while parked; the app has no automatic vehicle-motion detection. Full file browsing on the car screen and the original CarPlay audio template are not included in this video IPA.
